# Stage 85 — полная клеточная карта ландшафта Abyss Loop

## Результат

Stage 85 расширяет модель поля Stage84 с 80 фиксированных логических ландшафтных ID до полной сетки 19×14. Дорожная петля занимает 34 клетки; остальные **232 клетки каждой формы маршрута** являются клетками вне дороги и имеют стабильную координату.

## Реализовано

1. **Поле 19×14.** Визуальный слой перечисляет все позиции вне активной дорожной петли. Плитки остаются квадратными.
2. **Безопасное расширение ID.** Прежние `col:row` идентификаторы не переименованы и остаются валидны для существующих сохранений. Новые координаты используют отдельное пространство имён `m:col:row`, чтобы идентификаторы старого поля 10×8 не конфликтовали с координатами карты 19×14. В новых снимках записывается `field_schema: 3`.
3. **Стабильное отображение старых карт.** Уже размещённые старые ID сохраняют прежний способ проекции на экран; занятые старые позиции не дублируются как современные ID. Новые поля доступны на других свободных клетках.
4. **Зоны размещения.** `road` запрещена на ландшафтном поле; `roadside` допускает клетку, непосредственно примыкающую к дороге по стороне; `landscape` требует клетку за придорожной полосой. `any` остаётся доступной на свободной клетке. Правило применяется в validator и live preview.
5. **Геометрия секторов.** Современный ID связывается с ближайшим узлом фактического 34-клеточного контура, после чего слот преобразуется в индекс текущего логического маршрута. Поэтому секторная привязка учитывает `classic_ring`, `narrow_ring`, `deep_descent` и `fractured_loop`. Старые ID сохраняют прежнюю формулу сектора для обратной совместимости.
6. **Соседство.** По клеточным ID выполняются проверки соседей по четырём сторонам для синергий и обнаружения секретов; legacy ID используют прежнее 10×8 соседство.
7. **Сохранения.** Валидатор поддерживает схемы поля 1–3 и до 232 размещённых объектов; формат ID старых снимков не мигрируется насильно.
8. **QA.** Добавлены численные и source-level проверки Stage85, а также расширены связанные regressions и release preflight.

## Геометрические результаты

| Контур | Дорожных клеток | Клеток вне дороги |
|---|---:|---:|
| `classic_ring` | 34 | 232 |
| `narrow_ring` | 34 | 232 |
| `deep_descent` | 34 | 232 |
| `fractured_loop` | 34 | 232 |

Stage85 regression дополнительно проверяет 3 712 сопоставлений sector/index при нескольких длинах логического маршрута и разделяет придорожные клетки и глубину ландшафта. Это численная проверка алгоритма координат, не измерение качества визуального отображения.

## Проверки и ограничения

**Runtime status: runtime не подтверждён.** В данной среде нет исполняемого файла Godot 4.7.2.

- Целевая Stage85 regression: 17/17 source/numerical checks PASS.
- Полный Python static/regression suite: 111/111 PASS (отчёт `tests/reports/STATIC_TEST_REPORT.txt`).
- Stage84 regression остаётся в релизном наборе, чтобы сохранять предыдущие геометрические гарантии.
- **Godot 4.7.2 runtime не был выполнен**: исполняемый файл Godot недоступен в среде. Скриптовая компиляция, видимость на экране, реальные клики/касания, старые save-файлы в движке и новый Web export не объявляются проверенными. Подробные сценарии находятся в `FULL_LANDSCAPE_MAP_RUNTIME_CHECKLIST_STAGE85_RU.md`.

## Важное замечание по дорожной зоне

Zone validator и UI preview поддерживают `roadside`, включая проверку пользовательской карты с этим флагом. Текущие карточки баланса не были произвольно переведены в новую зону в рамках технического этапа: выбор конкретных существующих карт для roadside должен быть отдельным игровым/balance-решением.
