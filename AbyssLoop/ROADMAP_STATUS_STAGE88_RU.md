# Abyss Loop — статус Stage 88

**Stage 88: discovery mask и обратная связь размещения.** Проект `0.61.0`; runtime не подтверждён.

## Реализовано

- Экспедиция хранит `discovered_world_cells` как ограниченный словарь канонических modern ID `m:col:row`; идентификаторы карт и старые ключи `col:row` не меняются.
- На старте открывается небольшой участок возле начальной дорожной клетки; каждый посещённый узел раскрывает участок радиусом Манхэттена 3. Дорожные клетки не записываются в маску ландшафта.
- Поле сохраняется вместе с контрольной точкой. Восстановление фильтрует неизвестные ключи; старые сохранения без маски получают полностью открытую карту, сохраняя прежнее поведение.
- Save validator ограничивает маску 232 клетками и отклоняет некорректные ID, значения, клетки дороги и неверную схему поля.
- Неизведанные клетки визуально затемнены и отмечены `?`; предпросмотр размещения использует угловые скобки, а подтверждённые тайлы остаются заполненными плитками. Размещение на ранее неизвестной клетке не заблокировано.
- Превью, hit testing и игровая геометрия не переопределяют стабильные ID предметов/тайлов и не меняют боевые эффекты.

## Проверки

- Stage 88 regression: источник + независимая численная модель маски.
- Полный статический/regression suite: см. `tests/reports/STATIC_TEST_REPORT.txt`.
- Весь проект упаковывается через release packager с единым корнем `AbyssLoop/`.

Эти проверки не исполняют GDScript. Runtime не подтверждён до запуска Godot 4.7.2, фактического save/reload и свежего browser export.
