# Abyss Loop — дорожная карта разработки

**Prototype 61.0 RC7 · version 0.61.0**

## Самый свежий этап: Stage68C — Web export pipeline

Подготовлены Web preset, проверяемый экспортёр для Linux, preflight реального Web-артефакта, Chromium/Playwright smoke-test, локальный HTTP-сервер и GitHub Actions workflow с условной публикацией в GitHub Pages. Исходная проверка дала 7/7 не-проваленных проверок и 1 предупреждение. Это пока **подготовка**, а не подтверждённый runtime-релиз: Godot 4.7.2 и шаблоны экспорта не загрузились в контейнере из-за сетевых ограничений; переход Chromium к localhost блокируется политикой окружения; реальный Web artifact и публичная ссылка пока не получены.

Подробности: `ROADMAP_STATUS_STAGE68C_RU.md`, `STAGE68C_BUILD_REPORT_RU.md`, `WEB_EXPORT_RUNTIME_CHECKLIST_STAGE68C_RU.md`, `README_WEB_RU.md`.

## Открытые направления

- Runtime-приёмка Stage66A–C и Stage67 в Godot/Web: размещение тайлов, бой, статусы, обучение, события, босс и save/load.
- Stage64B: баланс на повторяемых реальных забегах, с данными из запущенной игры. Офлайн-модель не считается окончательным баланс-тестом.
- Stage68: финальная регрессия и решение о готовности 1.0 только после runtime-приёмки.

**Версия 1.0 не объявлена готовой.** Не меняем баланс на основании неподтверждённых предположений и не выдаём статические тесты за запуск движка.
