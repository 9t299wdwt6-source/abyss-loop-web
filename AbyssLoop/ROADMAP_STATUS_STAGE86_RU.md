# Abyss Loop — статус Stage 86

**Stage 86: процедурная генерация дорожных контуров.** Проект `0.61.0`, локальная development-сборка.

- Источник геометрии централизован в `TileSystem`; `RouteView`, placement preview и сохранения используют одинаковый контур.
- Новые экспедиции фиксируют `route_geometry_seed` в snapshot. Старые сохранения без поля получают seed `0` и сохраняют прежний фиксированный маршрут.
- Четыре семьи контуров поддерживают ограниченные seed-driven наружные обходы. Каждый контур содержит ровно 34 клетки, не выходит за отступ и остаётся простым ортогонально замкнутым циклом.
- Проверка seed-aware placement, route-sector assignment, key-cache и snapshot validation добавлена в общие пути геометрии.
- Stage86 regression: **17/17 PASS**; независимая модель охватывает **2 048 seed/profile scenarios**; полный Python static/regression suite: **112/112 PASS**.
- Результаты относятся к source-level и численным проверкам. GDScript compile/runtime не подтверждены: Godot 4.7.2 отсутствует в среде. Текущий Web URL недоступен веб-инструменту; свежая Web-сборка не опубликована.

1. Запустить `tests/smoke_test.gd` и сохранение/восстановление через Godot 4.7.2 stable.

3. Проверить размещение в дороге/придорожье/ландшафте и hit-testing на desktop и мобильном viewport.
4. Создать и запустить свежий Web export, затем выполнить браузерную приёмку с перезагрузкой страницы.
