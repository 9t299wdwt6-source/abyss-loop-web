# Stage 78 — ручной runtime-чек-лист

Заполнять только на точной сборке Stage 78 в Godot 4.7.2 stable. Чек-лист не отмечен выполненным автоматикой.

## Импорт и запуск

- [ ] Чистый импорт проекта без ошибок parse/type warnings.
- [ ] Главная сцена запускается; окно экипировки открывается без наложения или выхода за экран.
- [ ] Старый сохранённый забег без поля `field_cache` загружается с пустым тайником.
- [ ] Новый снимок сохраняет `field_cache`, содержимое ячеек и ID предметов после выхода/повторной загрузки.

## Контейнеры и ручной выбор

- [ ] Получить предмет при свободном рюкзаке: он появляется в рюкзаке.
- [ ] Заполнить все 12 ячеек рюкзака; получить обычный предмет, элитную вещь, боссовую реликвию и тайную реликвию в отдельных сценариях: новые вещи попадают в походный тайник, если там есть место.
- [ ] Проверить, что кнопка показывает заполненность рюкзака и тайника, а шесть ячеек тайника визуально отделены от двенадцати ячеек рюкзака.
- [ ] Выбрать вещь из тайника, посмотреть плюсы и минусы отдельных характеристик, наборы и синергии; не надевать её — состояние не меняется.
- [ ] Надеть вещь из тайника при полном рюкзаке: старая вещь возвращается в освободившуюся ячейку тайника, ID каждой вещи сохраняется ровно в одном временном контейнере/слоте.
- [ ] Снять надетую вещь при полном рюкзаке и свободной ячейке тайника: вещь поступает в тайник.
- [ ] Заполнить все 12 + 6 ячеек: снятие блокируется с понятным объяснением, удаление вещи освобождает ячейку.
- [ ] Получить ещё один предмет при заполненных обоих контейнерах: UI сообщает, что копия сохранена в постоянном арсенале; после возврата её можно найти в убежище.
- [ ] При ошибке сохранения смены экипировки оба контейнера и статы героя полностью откатываются.

## Завершение экспедиции

- [ ] Завершить забег добровольным возвращением: экран итога перечисляет предметы, бывшие в тайнике; арсенал содержит их копии.
- [ ] Проверить поражение: временные контейнеры не переопределяют правила сохранения ресурсов; найденная экипировка остаётся в постоянном арсенале по существующему правилу регистрации находок.
- [ ] Повторная попытка записи итога не дублирует предметы и не создаёт повторные ID.

## Экранные размеры

- [ ] 1440×900: все кнопки сравнения/надевания/возврата доступны; обе сетки прокручиваются вертикально.
- [ ] 1920×1080: текст бонусов и различий не обрезан.
- [ ] 390×844 portrait: панель сохраняет видимый футер, сетки имеют рабочие touch-targets и не выходят за экран.
