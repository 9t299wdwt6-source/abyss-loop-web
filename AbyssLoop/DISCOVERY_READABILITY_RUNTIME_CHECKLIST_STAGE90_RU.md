# Stage 90 — runtime checklist

Запускать на Godot 4.7.2 stable и на свежем Web export. Статические тесты не подтверждают GDScript runtime.

- [ ] Проверить счётчик исследования на новой экспедиции: значение не отрицательное, не превышает 232, дорожные клетки не считаются.
- [ ] После раскрытия ландшафта счётчик увеличивается; после сохранения/reload возвращается к прежнему значению.
- [ ] Неизведанные клетки скрывают биомную фактуру и читаются как туман, а не как уже открытый грунт.
- [ ] На `390×844` маркер `?`, пустая клетка, `+` (разрешено) и `X` (запрещено) различимы.
- [ ] На desktop/tablet счётчик не перекрывает заголовок, дорожные клетки, карту или всплывающую обратную связь.
- [ ] В high-contrast режимах маркеры различимы без опоры только на цвет.
- [ ] Реальные мышиные клики по дорожной и ландшафтной клеткам идут в нужный обработчик; тапы не сдвигают координаты.
- [ ] Тест не списывает карту при предпросмотре; подтверждённое размещение обновляет сетку и счётчик только по правилам.
- [ ] Сохранить screenshots desktop (`1440×900`), tablet (`620×420`) и phone (`390×844`); проверить отсутствие JS/console errors.
