# Stage 77 — runtime чек-лист предпросмотра тайлов

Выполнять в Godot 4.7.2 stable на точной сборке Stage 77.

## Дорожные тайлы

- [ ] Выбрать `ward`, навести на пустой узел рядом с существующим `cache` и увидеть `Контур снабжения` до клика установки.
- [ ] Проверить обратный порядок: выбрать `cache` рядом с уже установленным `ward`.
- [ ] Убедиться, что предпросмотр указывает фактический узел-триггер, а не только выбранную клетку.
- [ ] Проверить трёхузловую формацию на обычном участке и через шов последнего/первого доступного дорожного слота.
- [ ] Убедиться, что стартовый узел и занятые узлы выдают понятную причину запрета.
- [ ] Сравнить текст предпросмотра с реальным логом после посещения узлов; общий cap должен применяться ровно один раз на посещение.

## Ландшафт

- [ ] Навести на пустую допустимую клетку с надетым предметом, у которого совпадает `landscape_affinity`; увидеть реальные бонусы предмета.
- [ ] Проверить, что предмет из рюкзака без экипировки не предоставляет бонус.
- [ ] Проверить вывод тематического врага, если у ландшафта задан `enemy_pool`.
- [ ] Собрать соседнюю пару рецепта тайны и убедиться, что подсказка появляется до размещения, а открытие происходит только при посещении соответствующего сектора.
- [ ] Проверить, что разные route sector не образуют ландшафтную синергию.

## Сохранность и UI

- [ ] Убедиться, что наведение и прогноз не меняют `placed_tiles`, `world_tiles`, инвентарь и случайный генератор.
- [ ] При отказе установки выбранная карта и её индекс остаются стабильными.
- [ ] Проверить длину текста при 1440×900, 1920×1080 и 390×844; нет наложения кнопок и обрезки причины запрета.
- [ ] Запустить `tests/smoke_test.gd` и `tests/smoke_test_node.gd` через Godot; сохранить полный вывод.
- [ ] Зафиксировать версию движка и fingerprint именно этого ZIP в runtime-отчёте.

**Статус при создании чек-листа:** ожидает запуска; ни один пункт не отмечен как выполненный.
