# Abyss Loop — статус Stage 90

**Stage 90: читаемость разведанной карты и обратная связь размещения.** Проект `0.61.0`; статус — candidate; runtime не подтверждён для этой сборки.

## Выполнено

- Добавлен адаптивный короткий заголовок для компактного RouteView.
- Добавлен компактный счётчик `РАЗВЕДАНО n/232` в зарезервированном пространстве рядом с картой; он учитывает только канонические modern ID и исключает дорожные координаты активного маршрута.
- Туман неизвестных клеток сделан почти непрозрачным, с редким детерминированным рисунком и маркером `?`, адаптированным под малые размеры.
- Превью допустимого/недопустимого размещения получает размерный индикатор; на компактных клетках использует однобуквенные `+`/`X`, чтобы не обрезать знак.
- Сохранены правила размещения, ID карт, геометрия клеток и контракт совместимости старых сохранений.
- Добавлен `tests/stage90_discovery_readability_regression.py` с source contracts и численной проверкой целевых viewport.
