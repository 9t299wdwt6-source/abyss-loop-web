# Prototype 58 — ручная проверка разбора экспедиции

Использовать в Godot 4.7.2 stable после `RUN_RELEASE_GATE_WINDOWS.bat`. Это визуальный чек-лист; статические тесты не могут подтвердить фактическую отрисовку текста.

## Сценарии результата

- [ ] Безопасный возврат с завершённой целью, челленджем или контрактом показывает, что добыча сохранена и дополнительная цель выполнена.
- [ ] Обычный безопасный возврат предлагает вложить часть ресурсов в постоянное развитие или экипировку.
- [ ] Поражение с потерей редких ресурсов указывает фактическое количество потерянных редких ресурсов и рекомендует безопасное извлечение вне боя до критического риска.
- [ ] Раннее поражение без побед предлагает проверить оружие, броню и постоянные исследования.
- [ ] Поражение после нескольких циклов без победы над боссом даёт подсказку о подготовке к сильной цели.
- [ ] Завершённая длинная экспедиция распознаётся по `endgame_completed`; совет не сообщает о провале цели.
- [ ] Проваленный или незавершённый контракт получает отдельную рекомендацию; пустой контракт не создаёт ложного сообщения о провале.

## Визуальная и функциональная проверка

- [ ] Блок «РАЗБОР ЗАБЕГА · СЛЕДУЮЩИЙ ШАГ» расположен внутри области прокрутки отчёта и не перекрывает кнопку продолжения.
- [ ] Текст читаем при масштабах UI 85%, 100% и 110%, на окнах 1440×900 и 1920×1080.
- [ ] При повышенном контрасте шапка и текст совета остаются различимыми; подсказка не полагается только на цвет.
- [ ] Повторный просмотр/перестроение экрана результатов не изменяет ресурсы, награды, историю забегов или сохранённую экспедицию.
- [ ] После кнопки «Продолжить развитие убежища» возвращение на базу работает как прежде.

## Зафиксировать результат

- [ ] Приложить скриншот экрана результата безопасного возврата.
- [ ] Приложить скриншот результата поражения.
