# Stage68A — runtime checklist (Godot 4.7.2)

**Runtime acceptance:** все пункты ниже нужно выполнить в запущенном движке.

Отмечать только после проверки в реальном запуске; статические тесты не заменяют этот список.

- [ ] Открыть проект в Godot 4.7.2 stable; дождаться импорта без ошибок.
- [ ] Запустить `scenes/main.tscn`; нет ошибок парсинга/типизации GDScript.
- [ ] Начать новую экспедицию; проверить первый выбор тайла и оба типа размещения.
- [ ] Проверить запрещённое размещение: причина понятна, ресурс не списывается, карта остаётся в руке.
- [ ] Проверить роли врагов, элитную метку и все восемь маркеров статусов в бою.
- [ ] Проверить контекстное обучение: тайл, синергия, событие, перк, обычный бой, элита, телеграф босса, низкое здоровье.
- [ ] Проверить событие: маршрут заблокирован до выбора; после выбора состояние обновляется.
- [ ] Сохранить игру, закрыть приложение, загрузить сохранение и продолжить забег.
- [ ] Завершить бой/экспедицию; проверить итоговый экран и возврат на базу.
- [ ] Выполнить встроенные smoke, save-system и expedition integration checks.
- [ ] Сохранить логи и runtime gate report с версией Godot и fingerprint именно этой сборки.

Результат: не ставить PASS, пока каждый обязательный пункт не выполнен. На момент создания чек-листа все пункты ожидают runtime-проверки.
