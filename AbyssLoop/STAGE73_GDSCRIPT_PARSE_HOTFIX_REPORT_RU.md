# Abyss Loop — Stage 73: GDScript parse hotfix

## Причина
В пользовательском запуске Godot 4.7.2 появились ошибки:
- `scripts/ui/item_text_presenter.gd:46`: переменная `biome_label` выводила тип из результата `Dictionary.get()` (`Variant`); предупреждение считалось ошибкой.
- `tests/smoke_test.gd:593` и `tests/smoke_test_node.gd:421`: использовался необъявленный идентификатор `InventorySystemScript`, хотя в этих тестах класс подключён как `InventorySystemType`.

## Исправления
1. `biome_label` теперь явно объявлена как `String`, а значение из словаря явно преобразуется через `str(...)`.
2. Оба smoke-теста используют локально объявленный preload-идентификатор `InventorySystemType`.
3. Игровая логика, формат сохранений, ID контента и постоянная версия проекта не менялись.

## Проверки
- Полный статический набор: **100/100 PASS**.
- ZIP CRC: PASS.
- В архиве ровно одна корневая папка `AbyssLoop/`.
- GDScript runtime не запускался: Godot 4.7.2 отсутствует в текущей среде. Поэтому окончательное подтверждение требует повторного импорта/запуска в Godot на компьютере пользователя.

## Следующий шаг
Открыть этот архив в Godot 4.7.2, дождаться импорта и проверить, исчезли ли три ошибки. Если появится новая ошибка — прислать полный вывод; исправлять будем по фактическому сообщению, не продолжая наращивать механики поверх некомпилирующегося кандидата.
