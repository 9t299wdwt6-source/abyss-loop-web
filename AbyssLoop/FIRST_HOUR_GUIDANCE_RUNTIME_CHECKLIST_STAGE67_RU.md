# Stage67 — ручная приёмка первого часа в Godot 4.7.2

Отметить только после фактического прохождения на собранном ZIP; статические тесты не заменяют эти проверки.

- [ ] Новый профиль: обучение открывается первым, его можно закрыть, пропустить или открыть повторно через справку.
- [ ] Начать обычную экспедицию: панель «Первый шаг» видна; выбор карты и целевого дорожного узла / клетки ландшафта объяснён кратко и верно.
- [ ] После размещения одного тайла рекомендация обновляется, не перекрывает маршрут, клики по узлам и предпросмотр.
- [ ] Подходящая комбинация дорожных тайлов распознаётся, название и эффект совпадают с прогнозом / журналом.
- [ ] Подходящая комбинация ландшафтных тайлов распознаётся; неприменимое соседство не называется синергией.
- [ ] Во время обычного боя показана подсказка о роли врага и статусах; размещение по-прежнему заблокировано боевой логикой.
- [ ] Для элиты подсказка упоминает способность; телеграф атаки отображается в HUD.
- [ ] Во время босса учитываются фаза и метка «ГОТОВИТ УДАР»; панель не блокирует полосу здоровья и управление.
- [ ] При событии подсказка объясняет выбор; таймер маршрута остаётся приостановленным до выбора.
- [ ] При выборе улучшения подсказка видна и соответствует окну выбора.
- [ ] При HP не выше примерно трети появляется осторожный совет; кнопка возвращения продолжает соблюдать реальные ограничения боя/события.
- [ ] Закрыть приложение с активным сохранённым забегом, продолжить его: первая сессионная подсказка возвращается и отражает состояние сохранения.
- [ ] После первого завершённого забега панель скрывается на последующих экспедициях; обычная справка доступна.
- [ ] Проверить окно 1280×720 и более высокое разрешение, масштаб UI 100%/125%, высокий контраст и управление клавиатурой.

**Статус на момент сборки:** NOT RUN — движок в текущем окружении недоступен.
