# Дорожная карта Abyss Loop — Stage 83

**Этап:** сквозная проверка инвентаря, экипировки и завершения экспедиции.  
**База:** Prototype 0.61.0 / Stage 82.  
**Статус исходников:** полный статический набор прошёл 109/109, Stage 83 source guard — 15/15; runtime-прохождение не подтверждено в этой среде.

## Результат этапа

1. Добавлен изолированный runtime acceptance сценарий на реальных API `ExpeditionManager`, `InventorySystem` и `GameState`.
2. Сценарий проверяет 12 ячеек рюкзака, повторный ID, FIFO-вытеснение, начисление «Пыли утраченных вещей», ручную экипировку, checkpoint save/restore и уникальность экземпляров между рюкзаком и слотами.
3. Проверяются два исхода: безопасное возвращение сохраняет экипированные и переносимые предметы; поражение сохраняет экипировку, но теряет оставшийся рюкзак.
4. Повторный вызов settlement проверяется на отсутствие двойных выплат, повторного завершения экспедиции и дополнительных копий в арсенале.
5. Тест допускается только при `ABYSS_LOOP_RUNTIME_QA=1`; release gate запускает его в отдельной временной копии с отличительным именем проекта.
6. Релизный шлюз расширен до восьми runtime gates; без прохождения Stage 83 нельзя создать архив с меткой runtime-tested.

## Проверки

- Полный статический набор: 109/109 PASS; Stage 83 source guard: 15/15 PASS.
- Stage 83 source guard: 15/15 PASS; проверяет связь теста, сохранения и release gate.
- Runtime Acceptance: включён в release gate, но в текущей рабочей среде не выполнен, потому что Godot 4.7.2 не установлен и загрузка бинарного файла недоступна.
- Release preflight: проверяет обязательные документы, исходники сценария и единую структуру архива.
