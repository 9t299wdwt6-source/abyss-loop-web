# Дорожная карта Abyss Loop — Stage68C

**Статус:** подготовка Web-экспорта и непрерывной браузерной приёмки завершена на уровне исходников и инфраструктуры; реальный экспорт/публикация пока не подтверждены.

## Что сделано

- Добавлен preset `Web` с Compatibility renderer, выключенными Web threads и native extensions, автоматическим изменением размеров canvas и виртуальной клавиатурой для мобильного браузера.
- Добавлен Linux x86_64-скрипт экспорта Godot 4.7.2 stable. Он скачивает официальные бинарники и шаблоны, сверяет SHA-256, импортирует проект, экспортирует в `AbyssLoop_WebExport/index.html` и запускает preflight.
- Добавлен preflight исходников и готового экспорта: обязательные артефакты `.html/.js/.wasm/.pck`, размер/число файлов и ограничения типичного хостинга.
- Добавлен Chromium + Playwright smoke-test для доступности entry page, canvas, WebGL 2, загрузки JS/WASM/PCK, MIME типа WebAssembly, ошибок консоли и необработанных JS исключений.
- Добавлен локальный HTTP-сервер с явным MIME `application/wasm`.
- Добавлен GitHub Actions pipeline: установка Godot и экспортных шаблонов с проверкой контрольных сумм, импорт и Web export, браузерный smoke-test, сохранение отчётов и деплой в GitHub Pages только после успешного теста на ветке `main`.
- Добавлены статические регрессии для Web-настроек и отказа при неполном экспорте; требования включены в package/preflight audit.

## Результаты, которые подтверждены сейчас

- Исходная проверка Web-готовности: **7/7 не-проваленных проверок, 1 предупреждение**.
- Предупреждение относится к `DisplayServer.clipboard_set()` в диагностике, доступной только в debug-сборке; нужно перепроверить диагностические действия в реальной Web-сборке.
- У проекта используется `gl_compatibility`; C#-файлы и нативные расширения не обнаружены.
- Статические тесты и аудит комплектации проверяются отдельно после сборки.

## Что пока НЕ подтверждено

- Godot не запускался в этой рабочей среде: исполняемый файл и шаблоны экспорта не удалось скачать из-за DNS/сетевого ограничения.
- Chromium здесь установлен, но системная политика блокирует переход к localhost (`ERR_BLOCKED_BY_ADMINISTRATOR`), так что браузерный smoke-test реального экспорта не пройден.
- Настоящий `index.html/.js/.wasm/.pck` экспорт не создан; WebAssembly и WebGL 2 в сборке ещё не проверены.
- Публичная ссылка ещё не опубликована, потому что нет доступного подключённого репозитория/хостинга.

## Следующие действия

1. Подключить GitHub и загрузить эту полную сборку в репозиторий пользователя (или загрузить ZIP/исходники вручную).
2. Убедиться, что ветка называется `main`, включить GitHub Pages с источником `GitHub Actions`.
3. Запустить workflow `Abyss Loop Web Export and Browser QA`, дождаться успешных import/export и Chromium smoke tests.
4. Взять URL, который вернёт шаг GitHub Pages deploy, и вручную подтвердить мобильное отображение и сенсорные действия.
5. Лишь после этого использовать URL как основную браузерную среду для последующих циклов исправления и повторного тестирования.

**Release decision:** не готов объявлять 1.0. Stage68C — подготовленный pipeline; runtime acceptance и реальная публикация остаются открытыми.
