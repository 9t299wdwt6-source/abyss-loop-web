# Abyss Loop — статус Stage 85

**Stage 85: полная клеточная карта ландшафта и правила размещения.** Проект `0.61.0`; это локальная development-сборка, не подтверждённый релиз.

- Полная видимая карта: 19×14 = 266 клеток; каждый из четырёх контуров занимает 34 клетки дороги и оставляет 232 клетки вне дороги.
- Сохранения совместимы без массового переименования: исторические ID `col:row` остаются действительными, новые клетки используют имена `m:col:row`; снимок явно маркирует схему поля `field_schema: 3`.
- Новые клетки ландшафта валидируются против активной формы контура, получают сектор по ближайшему узлу дороги и используют общие проверки кликов/preview/размещения.
- Добавлена отдельная зона `roadside`: объект этой зоны должен соприкасаться с дорогой ортогонально. Карты `landscape` для новых ID размещаются в глубине поля; карты `road` на поле запрещены.
- Соседние клеточные синергии и обнаружение ландшафтных секретов используют единый типо-зависимый список соседей.
- Численный/source regression Stage85 проверяет все четыре контура, 232 клетки, 3 712 сочетаний размера маршрута и сектора, валидность зон и совместимость старых ключей.
