# Предварительная проверка релиз-кандидата — Prototype 59.0 RC5

**Версия проекта:** `0.59.0`  
**Статус:** RC5; runtime не подтверждён до реального запуска Godot 4.7.2.

## Область

- Версия проекта, README, build report, манифест, дорожная карта, чек-лист RC5, упаковщик и Windows-команды.
- Обязательные файлы включая `tests/save_integrity_regression.py` и `SAVE_INTEGRITY_RUNTIME_CHECKLIST_Prototype59.md`.
- Полный статический отчёт должен быть завершён без ошибок перед runtime gate.
- Архив проверяется на единственный корень `AbyssLoop/`, отсутствие дубликатов, запрещённых файлов и точное совпадение файлов с исходным деревом.

## Ограничение

Этот документ фиксирует контракт preflight. Точный результат последнего запуска доступен в stdout `tools/release_preflight.py`; данный файл не является отчётом runtime-прохождения и не заменяет Godot 4.7.2.
