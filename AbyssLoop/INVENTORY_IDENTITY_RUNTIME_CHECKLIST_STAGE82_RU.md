# Runtime checklist — Stage 82: identity invariants

**Duplicate-ID runtime acceptance пока не выполнен в Godot; duplicate кейсы ожидают прогона.** Использовать текущую сборку проекта Stage82 с Godot 4.7.2 stable, а не прежнюю Web Stage68C.

## Базовая проверка

- [ ] Запустить проект и выполнить `tests/smoke_test.gd` через штатный runner.
- [ ] Сгенерировать обычную находку, затем экипировать её правым кликом; один ID виден только в одном месте.
- [ ] Повторить надевание/выдачу того же ID: операция отклоняется, ячейки рюкзака не сдвигаются, журнал не пишет о новой находке.
- [ ] Заполнить 12 ячеек и получить новый предмет с уникальным ID: появляется в ячейке 01, старейший предмет вытесняется один раз, счётчик и пыль увеличиваются один раз.
- [ ] Вызвать попытку вставить существующий ID при заполненном рюкзаке: ничего не вытесняется, счётчики не меняются.

## Восстановление checkpoint

- [ ] В fixture checkpoint положить один корректный предмет в слот `weapon` и тот же ID в рюкзак; после загрузки экземпляр остаётся только в слоте.
- [ ] Добавить некорректное значение `slot` в экипировку; соответствующий слот очищается, валидные другие предметы сохраняются.
- [ ] Повторить один ID в двух слотах экипировки: остаётся первая корректная запись в порядке `EQUIPMENT_SLOTS`, другой слот очищается.
- [ ] Проверить старый checkpoint с `field_cache`: элементы после миграции входят в рюкзак без дубликатов, затем очередь ограничена 12 предметами.

## Сохранение и settlement

- [ ] Снять предмет с неполным рюкзаком: предмет помещается в начало рюкзака, слот пуст, бонусы героя пересчитаны.
- [ ] Снять предмет с заполненным рюкзаком: снятый предмет помещается в начало, старейший вытесняется ровно один раз.
- [ ] Смоделировать ошибку записи при снятии: состояние экипировки, рюкзак, журнал, ledger и `last_inventory_evicted_item` восстанавливаются.
- [ ] Безопасный возврат сохраняет экипировку и предметы из рюкзака, а вытесненные предметы не попадают в арсенал.
- [ ] Поражение сохраняет надетую экипировку согласно текущему правилу, неиспользованные предметы рюкзака не сохраняются; Echo Dust начисляется по правилу удержания.
- [ ] Повторить settlement с тем же `run_id`: награда не начисляется повторно.

## Web и устройство

- [ ] Экспортировать актуальный Stage82 в Web; убедиться, что CI artifact и preview относятся к одному commit SHA.
- [ ] Пройти сценарии на desktop viewport 1440×900 и 1920×1080.
- [ ] На мобильном портрете проверить тап по экипировке/рюкзаку и отсутствие горизонтального переполнения.
- [ ] Сохранить screenshot, GDScript output, JS console output и JSON результатов браузерного прогона.
