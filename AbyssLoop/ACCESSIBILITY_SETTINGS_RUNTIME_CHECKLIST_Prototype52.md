# Ручной runtime-чек-лист — Prototype 52: доступность и настройки

Проверять на Windows с Godot 4.7.2 после `RUN_RELEASE_GATE_WINDOWS.bat`. Отметки в этом файле означают ручную приёмку только после фактической проверки в запущенной игре.

## Сохранение и миграция

- [ ] Загрузить профиль, созданный в Prototype 45.2 / 50 / 51: ресурсы, исследования, экипировка, история и активный забег не потеряны.
- [ ] Старый профиль без новых ключей настроек получает разумные значения по умолчанию без ошибки загрузки.
- [ ] Изменить несколько настроек, закрыть и перезапустить игру; все выбранные параметры сохраняются.
- [ ] Сброс прогресса не должен неожиданно сбрасывать параметры доступности/отображения.

## Отображение

- [ ] Переключить масштаб 85% / 100% / 110%; изменение заметно применяется сразу и элементы остаются кликабельными.
- [ ] В режиме окна вернуться к окну 1440×900; переход в полноэкранный режим и назад работает без зависания и неправильного ввода мыши.
- [ ] Проверить убежище, подготовку экспедиции, карту, правую панель, события, перки, результат и окно настроек при 1440×900 и 1920×1080.
- [ ] На 85% важные действия не обрезаются; при 110% доступ к параметрам сохраняется через прокрутку окна настроек.

## Доступность

- [ ] Включить повышенный контраст; подписи, панели, кнопки и фокус различимы без опоры только на цвет.
- [ ] Выключить повышенный контраст; палитра возвращается к исходному оформлению.
- [ ] Включить уменьшение движения: маркер героя перестаёт плавно скользить по промежуточной позиции, а бой/таймеры не замедляются.
- [ ] Включить уменьшение вспышек; короткие сообщения карты остаются читаемыми без интенсивного цветового мигания.
- [ ] Проверить скорость анимации подсказок 0.5× / 1× / 1.5×; изменяется только длительность визуальной обратной связи, не скорость боя.
- [ ] Символьные метки `[!]`, `[+]`, `[-]` сопровождают названия эффектов; названия и таймеры остаются видимым текстом.
- [ ] Tab / Shift+Tab и Enter/Space доступны для новых селекторов, ползунка и переключателей; модальный фокус не уходит на фон.

## Релизная приёмка

- [ ] Нет обрезанного текста, перекрытий и невидимых кнопок в целевых размерах.
- [ ] Python static/regression suite проходит полностью.
- [ ] Godot 4.7.2 editor/import preflight, запуск главной сцены, gameplay smoke и save-system regression проходят.
