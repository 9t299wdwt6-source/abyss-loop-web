# Концепт Abyss Loop

`ABYSS_LOOP_CONCEPT_REFERENCE.png` — концепт-направление для пиксель-арт игры с многоуровневой бездной и **одним непрерывным замкнутым маршрутом**. На концепте нет боевых башен; точные игровые значения и фактический UI определяются исходниками проекта, а не изображением.

Это вспомогательный визуальный референс. Файл не загружается в игровую сцену и не заменяет интерактивный интерфейс Godot.
