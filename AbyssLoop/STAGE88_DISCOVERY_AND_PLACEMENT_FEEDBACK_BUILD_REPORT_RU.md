# Stage 88 — карта разведанных клеток и обратная связь размещения

Проект: Abyss Loop `0.61.0`. Статус: development-сборка; runtime не подтверждён.

## Изменения

1. Добавлена save-safe discovery mask `discovered_world_cells`, ограниченная современными map ID `m:col:row`.
2. Новые забеги начинают с открытой областью вокруг первого узла; дальнейшее исследование связано с посещением узлов пути. Маска записывается в snapshot и нормализуется при восстановлении.
3. Старые сохранения без маски мигрируют к полностью открытой карте, не меняя идентификаторы и размещённые объекты.
4. В `SaveSystem` добавлена проверка формы маски, максимального размера 232, boolean значений и запрета ключей, совпадающих с дорожными клетками для seed активного маршрута.
5. Неизведанные пустые клетки приглушены визуально и имеют маркер `?`; наведённый предпросмотр выделяется угловыми скобками, тогда как подтверждённые тайлы сохраняют плотную заливку и символ.
6. Панель предпросмотра сообщает, что клетка ещё не исследована; размещение карт на неизвестных клетках намеренно остаётся разрешённым, чтобы Stage 88 не вводил новое ограничение игрового баланса.

## Проверка

Stage 88 regression содержит 13 исходных контрактов и 8 независимых маршрутно-масочных сценариев. Полный статический набор проверяет совместимость этой работы с предыдущими системами. Такие проверки не исполняют GDScript и не подтверждают визуальное поведение в браузере.
