## Правило выпуска

Статические тесты сами по себе не подтверждают работу движка. Не создавать и не распространять `RUNTIME_TESTED` ZIP без успешного runtime gate с текущим fingerprint. Версия 1.0 допустима только после автоматических ворот и ручной приёмки.
