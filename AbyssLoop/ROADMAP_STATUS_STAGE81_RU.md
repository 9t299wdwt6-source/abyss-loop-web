# Abyss Loop — дорожная карта после Stage 81

**Текущий локальный этап:** Stage 81 — единый баланс вероятности выпадения и качества предметов.  
**Версия проекта:** `0.61.0` (без смены app ID/профиля и схемы на данном этапе).  
**Статус:** 107/107 статических проверок PASS; Godot runtime и новый браузерный экспорт не подтверждены.

## Сделано на уровне исходников

- Вероятность получения предмета отделена от вероятности редкости после успешного дропа.
- Базовая шкала качества: обычный 70%, редкий 24%, эпический 5,2%, реликтовый 0,8%; используется нормализованный weighted roll, а не аддитивное изменение единого `randf()`.
- Бонус качества от надетой экипировки (до 12 п.п.), подготовки (до 18 п.п.) и источника (элита +4 п.п., тайник +2 п.п.) ограничен общим cap 25 п.п.
- Общая формула вероятности источника используется для обычного противника (18%), элиты (не менее 45%), тайника (35%, cap 85%) и босса (100% по отдельному правилу именованной награды).
- Подготовленные бонусы и заряды эха расходуются только при успешном подходящем дропе.
- Элитная добыча сохраняет реально выпавшее качество и получает отдельный +10% параметрический premium вместо форсированного ранга.
- В UI показан шанс самого предмета и отдельное условное распределение качества. Журнал описывает успешные и неудачные броски разными сообщениями.
- Обновлены старые source guards, которые зависели от отменённой формулы; расширен runtime smoke сценариями seeded-статистики.
- Доступный старый опубликованный Web export — Stage68C; его скриншоты дают только историческое замечание по плотной панели экспедиции и тесным подписям убежища. Новый Stage81 export не опубликован.
