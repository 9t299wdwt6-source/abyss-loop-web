# Дорожная карта — Stage 82

**Текущий этап:** Stage 82 — целостность экземпляров предметов и сквозной аудит инвентаря. **108/108 PASS. Статус: исходники исправлены; runtime Godot 4.7.2 не подтверждён.**

## Выполнено

- Одна уникальная идентичность предмета на активную экспедицию: отказ от повторного ID до любых побочных эффектов.
- Дубликат не может вытеснить предмет FIFO-рюкзака и не создаёт ложную награду.
- Снятие экипировки поддерживает разрешённое исключение текущего слота, не допуская совпадения с другим слотом.
- Восстановление checkpoint нормализует шесть слотов, валидирует слот и ID, устраняет конфликт «экипировка + рюкзак» в пользу экипированного предмета.
- Ручная экипировка проверяет конфликт ID до изменения состояния.
- Stage82 regression включён в release-preflight и требования к ZIP.

## Остаётся проверить в Godot 4.7.2

1. Запуск `tests/smoke_test.gd` и парсинг всех скриптов проекта.
2. Восстановление специально подготовленного checkpoint с повторяющимися ID.
3. Ручное надевание и снятие с полным рюкзаком; корректность FIFO и «Пыли утраченных вещей».
4. Возврат и поражение, сохранение/перезагрузка, идемпотентность settlement.
5. Свежий Web export и браузерный тест актуальной Stage82 (старый опубликованный Stage68C для этого не подходит).
