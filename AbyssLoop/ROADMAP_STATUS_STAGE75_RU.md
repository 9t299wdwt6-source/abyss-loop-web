# Abyss Loop — статус дорожной карты, этап 75

**Основа:** Stage 74 — формации дорожных карт и экипировка картографа.  
**Версия проекта:** `0.61.0` (стабильное имя профиля и схемы сохранений не менялись).  
**Статус:** development build; статические проверки пройдены, Godot runtime не подтверждён.

## Изменения Stage 75

- [x] Добавлены дорожные карты `lost_convoy` («Обоз забытых исследователей») и `hunter_marker` («Охотничья веха»). Обе имеют `placement_zone = road`, недоступны в поле ландшафта и входят в общий взвешенный пул редких карт после действующего порога/разблокировки.
- [x] Редкая карта «Обоз» даёт +3 материала и готовит бонус к шкале редкости следующего успешного обычного/элитного предметного дропа: +12 п.п. за посещение, максимум +18 п.п.
- [x] Карта «Охотничья веха» готовит +15 п.п. к шансу выпадения экипировки за посещение, максимум +30 п.п. Компромисс: повышенный шанс встречи, сила врагов и боевая награда.
- [x] Оба бонуса сохраняются в ledger экспедиции, нормализуются при возобновлении старых/новых snapshot и проверяются валидатором сохранений. Бонусы не расходуются на безуспешный бросок или именную награду зарегистрированного босса; расходуются после успешного обычного/элитного предметного дропа.
- [x] Добавлен амулетный архетип `relic_scout` и суффикс `deep_catalogue`. `rare_find_bonus` ограничен 12 п.п., учитывается только от фактически надетой экипировки и влияет на шкалу редкости обычного выпавшего предмета.
- [x] `roll_item` принимает необязательный capped-бонус редкости. Без бонуса прежние пороги и поведение остаются прежними; при бонусе обычные дропы чаще переходят в более высокую категорию, а сила предмета и случайные аффиксы пересчитываются обычным путём.
- [x] Добавлены три синергии соседства и две трёхузловые дорожные формации с понятным соотношением риска и выгоды.
- [x] Предпросмотр карт объясняет подготовку предметной добычи; карточки используют общий механизм веса редких карт и улучшение картографа.
- [x] Добавлены regression-guards для новых карт, ограничений бонусов, сохранения ledger, экипированного бонуса и монотонности шкалы редкости; расширен `tests/smoke_test.gd` для будущего запуска в Godot.
- [x] Stable-ID manifest обновлён для добавленных ID; прежние идентификаторы не переименовывались.
