# Abyss Loop — статус Stage 89

**Stage 89: интеграционная приёмка карты и маски исследования.** Проект `0.61.0`; runtime не подтверждён.

## Включено

- В Godot runtime acceptance добавлена проверка стартовой маски исследования для действующей экспедиции.
- Каждая открытая клетка должна иметь канонический modern ID `m:col:row`, значение `true` и находиться вне 34-клеточного дорожного контура активного `route_geometry_seed`.
- Проверяется раскрытие новых клеток после вызова механики исследования на отдалённом узле маршрута.
- Снимок должен сохранять точную маску исследования и seed геометрии; восстановленный менеджер должен вернуть те же значения.
- Отдельный тест восстанавливает снимок до Stage 88 без `discovered_world_cells` и проверяет безопасную миграцию к полному открытию 232 свободных клеток.
- Новый Python regression contract проверяет, что сценарий подключён к autoload-aware runtime runner, который уже исполняется в GitHub Actions workflow.

## Результаты локальной проверки

- Полный статический набор Stage 88 перед изменениями: `114/114 PASS`.
- Добавлена Stage 89 source-contract regression для runtime gate.
- В данной среде Godot 4.7.2 не установлен, сеть/DNS недоступны. Локальный Chromium блокирует HTTP переход к localhost (`ERR_BLOCKED_BY_ADMINISTRATOR`). Поэтому Godot runtime и browser acceptance именно этой сборки не объявляются пройденными.
- Последний доступный GitHub Actions runtime/browser acceptance относится к старому deploy и не заменяет приёмку изменений Stage 88/89.

## Обязательная следующая проверка

После публикации исходника Stage 89 CI должен исполнить `res://tests/expedition_runtime_acceptance_runner.tscn` в Godot 4.7.2. Проверяются discovery mask, placement, save/restore, старый формат снимка, реальная отрисовка и браузерные клики. Не считать этап runtime-принятым до успешного запуска этой проверки.
