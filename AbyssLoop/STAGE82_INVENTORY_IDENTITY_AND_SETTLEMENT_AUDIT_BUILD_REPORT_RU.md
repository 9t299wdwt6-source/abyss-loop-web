# Stage 82 — целостность экземпляров предметов и сквозной аудит инвентаря

## Результат

Аудит duplicate item IDs устраняет ложные успехи при повторном добавлении. Полноценный runtime не подтверждён в этом окружении.

Stage 82 укрепляет общий путь предмета между добычей, экипировкой, FIFO-рюкзаком и восстановлением checkpoint. Версия проекта остаётся `0.61.0`; стадия не объявляется runtime-проверенной без запуска в Godot 4.7.2.

## Исправления

1. **Идентичность предмета уникальна внутри экспедиции.** `_store_run_item()` теперь отклоняет предмет, ID которого уже есть в рюкзаке или в другом слоте экипировки. Раньше повтор ID в рюкзаке возвращал `true`, хотя новый экземпляр не помещался — этот результат мог выглядеть как успешный дроп и приводить к расходованию одноразовых бонусов.
2. **Проверка до вытеснения.** Дубликат проверяется до очистки `last_inventory_evicted_item` и до `pop_back()`. Отказ не изменяет размер рюкзака, число вытеснений или накопленную «Пыль утраченных вещей».
3. **Безопасное снятие предмета.** `_store_run_item(item, except_equipped_slot)` разрешает перенести предмет из своего текущего слота в рюкзак, но отклоняет ID, принадлежащий другому слоту или уже лежащий в рюкзаке. Если сохранение снятия не удаётся, прежняя экипировка и очередь откатываются.
4. **Ремонт старых/повреждённых checkpoint.** Восстановление строит каноническую карту из шести поддерживаемых слотов, проверяет соответствие `slot` и `id`, сохраняет не более одного экземпляра ID в экипировке и удаляет совпадающие ID из рюкзака. При конфликте приоритет остаётся у корректно надетого предмета.
5. **Защита ручной экипировки.** Перед переносом из рюкзака проверяется, что тот же ID ещё не экипирован. Это дополнительная защита от повреждённого состояния, не меняющая обычный интерфейс.
6. **Проверки регрессии.** Добавлен Stage82 source-level тест и runtime-smoke asserts для дубликатов: отказ не должен вызывать вытеснение или начислять ресурс за вытеснение.

## Проверки

- Полный статический набор: **108/108 PASS**.
- Stage82 regression: **10/10 PASS**.
- Проверка независимого release-preflight и структуры ZIP выполняется перед упаковкой.
- Проверка GDScript компилятором, реального восстановления checkpoint, перетаскивания, сохранения после ошибки записи и свежего браузерного экспорта не подтверждена: в рабочем окружении отсутствует исполняемый Godot 4.7.2. Runtime asserts добавлены в `tests/smoke_test.gd`, но их наличие не считается доказательством исполнения.
